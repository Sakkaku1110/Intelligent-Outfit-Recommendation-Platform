智能衣柜推荐系统

基于 SS928 边缘端、WS63 传感器节点与移动端应用，实现衣物拍照录入、人工审核、衣柜管理，以及天气和场景驱动的可解释穿搭推荐。

若播放器未正常加载，可直接打开或下载原视频。

演示内容

  • 衣物拍照采集、识别草稿与人工审核入库
  • 真实衣柜数据的浏览、筛选、编辑与云端同步
  • 基于天气、场景、偏好和衣物属性的穿搭推荐
  • WS63 与 AS7341 光谱数据对材质判断的辅助

项目边界

当前项目是可演示的 MVP 原型。推荐采用规则打分与轻量特征匹配；视觉识别样本规模较小，因此入库流程保留人工审核与修正。
